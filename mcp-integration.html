MCP Integration - Extending TRAE's capabilities

Connect TRAE to external tools, APIs, and services

What is MCP?

MCP (Model Context Protocol) is an open standard that allows AI assistants like TRAE to connect to external tools, data sources, and services. It provides a standardised way for AI models to interact with the world beyond the code editor.

Why Use MCP Integration?

MCP integration extends TRAE's capabilities beyond code generation and editing:

  • Database Access: Query databases directly from TRAE
  • API Interaction: Call external APIs and process responses
  • Documentation Lookup: Access up-to-date library and framework docs
  • File System Operations: Perform complex file operations across your project
  • Custom Tools: Build and integrate your own specialised tools

Tip

MCP is heavy on context window usage. Each MCP tool call adds data to your conversation context. Only enable MCP servers you actually need for your current task to avoid hitting context limits and unnecessary costs.

Best Practices

  • Start Simple: Begin with one or two MCP servers and expand gradually
  • Monitor Performance: Watch for slow MCP servers that impact TRAE's responsiveness
