14 Essential Skills

TRAE Solo comes with 14 built-in skills — specialized AI agents that handle specific tasks with expert-level proficiency

Overview

Skills are pre-configured AI sub-agents that specialize in specific development tasks. Instead of asking the general-purpose AI to do everything, you can delegate to specialized skills that follow proven methodologies. Each skill comes with its own set of rules, prompts, and best practices.

How to activate a skill

Type /skill-name in your TRAE chat or use the skill menu in the UI. Skills appear as sub-agents that you can invoke directly or let TRAE auto-suggest when appropriate.

Complete Skill Reference

brainstorming +

Purpose: Ideation and creative exploration before implementation.

  • Generates multiple approaches to a problem
  • Explores trade-offs between different solutions
  • Helps clarify requirements and user stories
  • Creates user journey maps and flow diagrams
▶ Example prompt
/brainstorming Brainstorm different ways to implement user authentication for a React app. Consider security, UX, and developer experience trade-offs.
canvas-design +

Purpose: Create beautiful visual art in .png and .pdf documents using design philosophy.

  • Create original visual designs and posters
  • Generate art, designs, and static visual pieces
  • Avoids copying existing artists' work
  • Outputs production-ready image files
▶ Example prompt
/canvas-design Create a poster for a tech conference with a modern, minimalist design using gradients and geometric shapes.
chart-visualization +

Purpose: Intelligently select and generate the most suitable chart type from 26 available options.

  • Auto-selects best chart type based on data structure
  • Supports 26 chart types (bar, line, pie, scatter, heatmap, etc.)
  • Extracts parameters based on detailed specifications
  • Generates chart images using JavaScript
▶ Example prompt
/chart-visualization Create a visualization showing monthly revenue growth over the past year with a target line overlay.
data-analysis +

Purpose: Analyze Excel (.xlsx/.xls) or CSV files for statistics, summaries, and insights.

  • Supports multi-sheet Excel workbooks
  • Performs aggregation, filtering, and joins
  • Creates pivot tables and statistical summaries
  • Exports results to CSV/JSON/Markdown
  • SQL query generation for complex analysis
▶ Example prompt
/data-analysis Analyze this sales dataset to find the top 5 products by revenue per region, and export the results as a summary table.
doc-coauthoring +

Purpose: Guide users through a structured workflow for co-authoring documentation.

  • Walks through documentation writing step-by-step
  • Supports PRDs, technical specs, decision docs
  • Helps transfer context efficiently
  • Iterative content refinement
  • Verifies docs work for intended readers
▶ Example prompt
/doc-coauthoring Help me write a technical specification for our new API endpoint authentication.
figma +

Purpose: Figma MCP integration for design-to-code workflow.

  • Fetches design context, screenshots, variables from Figma
  • Translates Figma nodes into production code
  • Handles Figma URL/node-ID references
  • Supports Figma MCP setup and troubleshooting
▶ Example prompt
/figma Fetch the design from https://figma.com/file/xxx?node-id=123:45 and implement it as a React component.
frontend-design +

Purpose: Create distinctive, production-grade frontend interfaces with high design quality.

  • Builds web components, pages, dashboards, React components
  • Generates creative, polished code and UI
  • Avoids generic AI aesthetics
  • Handles HTML/CSS layouts, styling, and beautification
▶ Example prompt
/frontend-design Build a landing page for our product with a hero section, feature cards, testimonials, and a CTA footer.
frontend-skill +

Purpose: Build visually strong landing pages, websites, apps, prototypes, demos, or game UIs.

  • Enforces restrained composition and image-led hierarchy
  • Focuses on cohesive content structure
  • Uses tasteful motion and animation
  • Avoids generic cards, weak branding, and UI clutter
▶ Example prompt
/frontend-skill Create a product demo page with a strong visual hierarchy and immersive scroll-based animations.
git-commit +

Purpose: Generate meaningful, conventional commit messages from code changes.

  • Analyzes git diff to understand changes
  • Generates conventional commit messages (feat, fix, refactor, etc.)
  • Provides clear, descriptive commit summaries
  • Follows best practices for version control hygiene
▶ Example prompt
/git-commit Generate a commit message for the current staged changes following conventional commit format.
impeccable +

Purpose: Design, critique, polish, and optimize frontend interfaces across websites, dashboards, components, and UI systems.

  • UX review and visual hierarchy analysis
  • Information architecture and cognitive load assessment
  • Accessibility, performance, and responsive behavior
  • Theming, typography, spacing, layout, alignment, color
  • Motion, micro-interactions, and UX copy
  • Error states, edge cases, and reusable design tokens
▶ Example prompt
/impeccable Review the dashboard design and suggest improvements for better visual hierarchy and accessibility.
skill-creator +

Purpose: MANDATORY tool for creating new skills.

  • Creates new skill definitions and configurations
  • Must be invoked immediately when user wants to add any skill
  • Handles skill scaffolding and registration
▶ Example prompt
/skill-creator Create a new skill for automated accessibility testing of React components.
vercel-composition-patterns +

Purpose: React composition patterns that scale — compound components, render props, context providers.

  • Addresses boolean prop proliferation
  • Builds flexible component libraries
  • Designs reusable component APIs
  • Includes React 19 API changes
  • Triggers on compound components and render props tasks
▶ Example prompt
/vercel-composition-patterns Refactor this Modal component to use the compound component pattern with proper context.
vercel-react-best-practices +

Purpose: React and Next.js performance optimization guidelines from Vercel Engineering.

  • Optimal React component patterns
  • Next.js page optimization
  • Data fetching best practices
  • Bundle optimization techniques
  • Performance patterns and anti-patterns
▶ Example prompt
/vercel-react-best-practices Review this dashboard page for performance issues and suggest optimizations.
webapp-testing +

Purpose: Toolkit for testing local web applications using Playwright.

  • Interacts with and tests web applications
  • Verifies frontend functionality
  • Debugs UI behavior
  • Captures browser screenshots
  • Views browser logs and console output
  • Supports navigation, clicks, form fills, and assertions
▶ Example prompt
/webapp-testing Navigate to http://localhost:3000/login, fill in the form with test credentials, click submit, and verify the dashboard loads.
